# Wblzy Vault — Pure OLED Black Liquid Glass Edition

## 1. Deploy on GitHub + Vercel
1. Upload all files (including `api/auth.js`) to your GitHub repository and import into Vercel.
2. Go to **Vercel Project -> Settings -> Environment Variables** and add:
   - `ADMIN_USER` = your chosen admin ID
   - `ADMIN_PASS` = your strong secret password
3. Click **Redeploy** in Vercel.

## 2. Connect Supabase (For Live Public Storage)
1. Create a free project at **supabase.com** and run in **SQL Editor**:
```sql
CREATE TABLE files (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  caption TEXT NOT NULL,
  file_url TEXT NOT NULL,
  thumb_url TEXT,
  file_size TEXT,
  downloads INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE announcements (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  message TEXT NOT NULL,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE files DISABLE ROW LEVEL SECURITY;
ALTER TABLE announcements DISABLE ROW LEVEL SECURITY;
```
2. Create a **Public** bucket named `vault` in **Storage**.
3. Paste your Supabase URL and Anon Key inside `config.js`.
